# Condobook - Landing Page

Landing page moderna, responsiva e de alta conversão para o **Condobook**, plataforma completa de gestão condominial.

## 🚀 Tecnologias Utilizadas
- HTML5 semântico
- CSS3 puro (Grid, Flexbox, Animações 3D com `perspective` e `transform-style: preserve-3d`)
- JavaScript Vanilla (Interações, Parallax, Tilt 3D, contadores animados e abas dinâmicas)
- Google Fonts (`Plus Jakarta Sans`)

## 📁 Estrutura do Projeto
```
Condobook/
├── assets/
│   └── logo.png        # Logo oficial com transparência
├── css/
│   └── style.css       # Estilos, sistema de design e animações 3D
├── js/
│   └── main.js         # Interações, observadores de scroll e animações
├── index.html          # Estrutura completa da landing page
└── README.md
```

## 💻 Como Executar Localmente
Como o projeto utiliza tecnologias web nativas sem dependências pesadas de build, você pode:

1. Abrir diretamente o arquivo `index.html` em qualquer navegador moderno.
2. Ou rodar via servidor local (ex: Python ou VS Code Live Server):
   ```bash
   python -m http.server 3000
   ```
   Acesse: `http://localhost:3000`
